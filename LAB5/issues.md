# Static Code Analysis Issues Log

This document records the static code analysis findings for `bank_account_system.py` using **Bandit**, **Pylint**, and **Flake8**, along with their severity, descriptions, and corresponding fix approaches.

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| Insecure MD5 Hashing (`B324`) | Security (Bandit - High) | 44 | Uses insecure/weak MD5 hash algorithm for PIN hashing (`hashlib.md5`). MD5 is vulnerable to collision and preimage attacks. | Replace with SHA-256 (`hashlib.sha256`) or pass `usedforsecurity=False` (or a dedicated password hasher like SHA-256 with salt). |
| Command Injection via Shell (`B605`) | Security (Bandit - High) | 55 | Calls `os.system("echo Backup complete: " + filename)` using the system shell, vulnerable to command injection if filename is untrusted. | Remove `os.system` and replace with standard Python `print()` or safe file logging. |
| Insecure `eval()` Usage (`B307` / `W0123`) | Security / Bug (Bandit - Medium / Pylint) | 39 | Executes arbitrary expressions using `eval(expr)`, which allows remote arbitrary code execution. | Parse expression safely or use arithmetic validation / `ast.literal_eval` or compute bonus directly using safe numerical operations. |
| Weak Pseudo-Random Number Generator (`B311`) | Security (Bandit - Low) | 48 | Uses standard `random.randint` for generating security-sensitive temporary PINs, which is pseudo-random and predictable. | Use the cryptographically secure `secrets` module (`secrets.randbelow` or `secrets.choice`). |
| Bare `except:` & Try-Except-Pass (`B110` / `E722` / `W0702`) | Bug / Code Smell (Bandit - Low / Flake8 / Pylint) | 22-23 | Bare `except:` catches all exceptions indiscriminately (including `KeyboardInterrupt`, `SystemExit`) and silently suppresses errors with `pass`. | Catch specific expected exceptions (e.g. `KeyError`, `TypeError`) and log/handle appropriately instead of silent failure. |
| Mutable Default Argument (`W0102`) | Bug (Pylint) | 11 | `transactions=[]` uses a mutable default list shared across all calls, causing cross-account transaction contamination. | Set default parameter to `None` and initialize `transactions = []` inside the function if `None`. |
| Singleton Comparison with `== None` (`E711` / `C0121`) | Style / Best Practice (Flake8 / Pylint) | 28 | Uses `== None` to check for missing keys instead of identity check `is None` or idiomatic `if acc_id not in account_data:`. | Change comparison to `is None` or check `acc_id not in account_data`. |
| Unused Imports and Variables (`F401` / `F841` / `W0611` / `W0612`) | Code Quality (Flake8 / Pylint) | 6, 27, 38 | `sys` is imported but never used. `service_fee` is assigned but never deducted. `bal` is assigned but only implicitly targeted via string eval. | Remove unused `sys` import. Incorporate or remove unused `service_fee`. Properly utilize balance in computation. |
| Missing Function Docstrings & Naming (`C0116` / `C0103`) | Code Quality / Style (Pylint / PEP 8) | 11, 19, 26, 37, 43, 47, 51, 58 | Functions lack docstrings explaining inputs/outputs, and `createAccount` violates snake_case convention. | Add informative docstrings to all functions and rename `createAccount` to `create_account` (maintaining backward compatibility alias if needed). |
| Unspecified Encoding & Resource Handling (`W1514` / `R1732`) | Resource Management (Pylint) | 52 | File `open(filename, "w")` does not specify encoding and does not use context manager `with`, risking file descriptor leaks. | Use `with open(filename, "w", encoding="utf-8") as f:` for safe automatic resource cleanup. |
